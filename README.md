# Gradinko Studio

Локален визуален редактор за съдържанието на сайта Gradinko. Никакъв
бекенд, никакви потребителски акаунти. Студиото съществува само за
вътрешна употреба и не се деплоява заедно с публичния сайт.

## Защо отделно от gradinko

Vercel-проектът на публичния сайт е конфигуриран с **Root Directory =
`gradinko/`**. Vercel не вижда нищо извън тази папка, така че Studio
никога не става част от публичния деплой — нулева площ за атаки върху
видимия сайт.

## Как се ползва (за нетехнически потребител)

1. Отвори URL-а на Studio (вътрешен Vercel линк или локално
   `npm run dev`).
2. Редактирай секциите от лявото меню — Бранд, Начало, Услуги, За нас,
   Галерия, Свои секции, Контакти, Футър.
3. За Галерията: кликни „+ Добави снимка“, влачи или избери файл от
   диска, въведи име и (по избор) цена. Влачи редовете за пренареждане.
4. Промените се виждат веднага в десния панел.
5. Кликни „Експорт ↓“ и избери:
   - **Готов сайт** — ZIP с целия сайт. Качи го директно в хостинг.
   - **Само съдържание** — content.json + папка със снимки за разработчика.

## За разработчика — локално

```bash
cd studio
npm install
npm run dev   # автоматично билдва gradinko и копира dist/ в public/template/
```

`prepare-template` се изпълнява автоматично преди `dev` и `build`.

## Деплой

Може да се деплойне като отделен Vercel проект със **Root Directory =
`studio/`** и `Build Command = npm run build`. URL-ът трябва да остане
непубличен (можеш да го защитиш с Vercel Password Protection).

Алтернативно, отвори локално: `npm run build && npm run preview`.
